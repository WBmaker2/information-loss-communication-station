# 2026-07-18 초등학생 실사용성 확인 기록

## 확인한 흐름

- 3~4학년 기본 활동에서 연습 2단계, `비 오는 날 모임 장소`의 두 비교, 전체 보기, 뜻을 지킨 문장 선택, 결과와 완료 기록까지를 Chromium E2E로 확인했습니다.
- 5~6학년 도전 활동에서 `방과 후 일정은 아직 예정`의 예정→확정 변화와 `가상 학교 방송 이어 전하기`의 두 안전 전달문을 확인했습니다.
- 선택 복구, 연습·비교·전체 보기·전달문 화면의 뒤로가기, 키보드 Tab·Enter·Space, 360px·390px 화면과 200% 확대, axe 심각도, 저장소·쿠키 없음도 같은 전체 E2E에 포함해 통과했습니다.

## 해결된 마찰

- 오답 뒤에는 현재 학생용 피드백으로 다시 살펴볼 지점을 알려 주고, `고른 것 지우기`로 문장·이유·피드백을 함께 비울 수 있습니다.
- 다음으로 가기 전에 `먼저 내 답 확인을 눌러요.` 안내를 보이고, 뒤로 돌아와도 이미 찾은 변화와 완료 기록은 유지합니다.
- 결과에는 실제로 찾은 변화와 `이유`만 남기며, `확인한 변화가 없어요.` 같은 빈 결과 반복이 보이지 않음을 확인했습니다.

## 390×844 화면 캡처 상태

루트 권한 Chromium에서 390×844 production 비교 화면을 실제로 캡처했고, `scrollWidth`가 390px인 것을 확인했습니다. 첫 결과 화면 캡처에서는 전달문 화면의 아래 스크롤 위치가 남아 결과 제목이 잘린 것을 발견했습니다. 화면이 바뀔 때 맨 위로 돌아가도록 보완하고, 결과 전환 직전 스크롤 뒤 `window.scrollY === 0`을 확인하는 회귀 E2E를 추가했습니다.

현재 `compare-mobile.png`와 `result-mobile.png`는 최종 캡처 전에 덮어쓸 작업 중인 파일입니다. 이 코드·문서 커밋에는 넣지 않고, 다음 검증 단계에서 수정 뒤 실제 화면으로 다시 캡처합니다.

## 교실에서 남은 확인 항목

- 3~4학년 학생이 교사 설명 없이 첫 선택과 `고른 것 지우기`의 뜻을 이해하는지 관찰합니다.
- 실제 교실 기기(태블릿·작은 노트북)에서 390px보다 작은 폭과 브라우저 확대 상태를 다시 확인합니다.
- 방과 후 일정처럼 실제로 바뀔 수 있는 안내를 수업에서 다룰 때, 가상 사건이라는 범위를 교사가 먼저 알려 줍니다.
