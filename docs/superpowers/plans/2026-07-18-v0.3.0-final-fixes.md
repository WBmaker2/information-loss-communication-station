# v0.3.0 최종 리뷰 보완 계획

## 목표

비교 화면에서 `고른 것 지우기`를 눌러도 학생이 고른 변화 종류는 유지하고, 선택 복구와 최종 모바일 결과 증거를 회귀 가능하게 남깁니다.

## 작업 순서

1. E2E에 비교 화면 변화 종류 보존과 연습 과다 선택 피드백·초기화를 먼저 추가해 RED를 확인합니다.
2. 비교용 초기화 함수를 추가해 문장, 이유, 피드백만 지우도록 수정합니다.
3. 고유한 390×844 최종 결과 PNG를 문서에서 직접 링크하고 검증 기록을 갱신합니다.
4. 전체 단위·타입·린트·빌드·E2E와 diff 검사를 다시 실행합니다.
5. 키보드 E2E helper는 각 입력 뒤 화면 전환 완료를 기다려 React 렌더 경계의 race를 막습니다.

## 완료 기준

- 비교 화면에서 `뜻이 바뀜`을 고른 뒤 선택을 지워도 해당 라디오가 유지됩니다.
- 연습 화면의 과다 선택은 정확한 피드백을 보이고, 지운 뒤 선택과 피드백이 모두 비워집니다.
- 최종 결과 스크린샷은 기존 파일과 별도 고유 파일로 보존되고 두 검증 문서가 그 파일을 링크합니다.
