# 뜻 변화 판정 기준

| 유형 | 확인 질문 | 예 |
| --- | --- | --- |
| 뜻 유지 | 낱말이 달라도 같은 뜻 조각이 남았나요? | 모둠별 = 각 모둠 |
| 빠짐 | 원문에 있던 뜻 조각이 다음 문장에서 없어졌나요? | 우천 조건 누락 |
| 근거 없는 추가 | 원문에 없는 내용을 새로 더했나요? | 확인되지 않은 불이익 |
| 뜻이 달라짐 | 범위·수량·시간·대상·확실성이 바뀌었나요? | 최대 두 개 → 두 개 |

판정은 바로 이웃한 두 단계만 비교합니다. 여러 변화가 있으면 각각의 표현 조각과 뜻 근거를 확인합니다.
