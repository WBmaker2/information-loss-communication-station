# 2026-08-31 초등학생용 문장·표현 점검

## 점검 방법

초3~4 준호가 긴 문장을 건너뛰고 버튼을 먼저 누른다는 가정으로 시작 화면·연습·비교·다시 보내기 흐름을 읽고 조작했습니다. 문장마다 한 번에 할 행동이 하나인지, 어려운 낱말에 바로 뜻이 붙는지, 틀렸을 때 고치는 방법이 보이는지를 확인했습니다.

## 바꾼 표현

| 위치 | 이전 표현의 문제 | 적용한 표현 | 기대하는 이해 |
| --- | --- | --- | --- |
| 시작 제목 | “전해지는 동안 달라진 뜻을 찾아 안전하게 다시 보내요”가 길고 추상적 | “달라진 말을 찾아 뜻을 지켜요” | 활동 목적을 짧게 기억 |
| 시작 설명 | 문장이 길고 질문형 설명이 먼저 나옴 | “두 문장을 비교하고, 다시 안전하게 전해요.” | 순서를 두 동사로 예측 |
| 학년 카드 | “보이는 뜻”, “누가 알려 줬는지”가 길게 이어짐 | “시간·장소·수량의 뜻”, “조건·출처·예정/확정” | 학년별 관찰 대상을 빠르게 찾음 |
| 첫 선택 | “두 문장에서 달라진 말을 눌러 보세요”가 실제 판정과 어긋남 | “이전/다음 문장에서 사라진/달라진 말 하나를 눌러요. ‘…’” | 한쪽·한 조각으로 시작 |
| 변화 종류 | 네 선택지를 긴 문장으로 설명 | “빠짐·추가·뜻 바뀜·같은 뜻 중 어디인지” | 선택지 의미를 비교 |
| 근거 | “근거”만으로는 성인용 표현에 가까움 | “문장에서 이유가 되는 말을 골라요.” | 왜 고르는지 연결 |
| 오답 회복 | 다시 살펴보라는 말만 있어 다음 행동이 모호함 | “틀렸어요. 고른 말과 변화 종류를 다시 살펴보고, 내 답 확인을 눌러요.” | 확인 버튼으로 재시도 |
| 전달문 조합 | 안전한 문장과 틀린 문장을 함께 남겨도 완료 가능 | “잘못 고른 문장은 다시 눌러 취소하고, 뜻을 모두 지킨 문장만 남겨 보세요.” | 선택 취소라는 회복 행동을 예측 |

## 난이도 판정

- `조건(어떤 때인지)`, `출처(누가 알려 줬는지)`, `확실성(예정인지 확정인지)`은 기존 학생용 레이블을 유지했습니다. 각 레이블이 의미를 바로 풀어 주므로 교과 정확성을 해치지 않고 초등학생이 읽을 수 있습니다.
- “한 번에 하나씩만 해도 괜찮아요”, “작은 예”를 유지해 실패 부담을 낮췄습니다.
- 내부 구현 용어(전이, 원문, 뜻 장부, 표현 조각 등)는 학생 화면에 추가하지 않았습니다.

## 검증 질문

1. 지금 어느 문장을 눌러야 하나요? → 안내 카드에 `이전 문장` 또는 `다음 문장`과 실제 문장 조각이 함께 보입니다.
2. 몇 개를 눌러야 하나요? → “하나”와 선택 조각의 `gi-pulse`가 보입니다.
3. 틀리면 어떻게 하나요? → 오답 피드백과 `고른 것 지우기`, 잘못된 전달문을 다시 누르는 방법이 보입니다.
4. 다음 버튼은 언제 누르나요? → 정답 확인 후에만 활성화되고 활성 순간 `gi-pulse`가 켜집니다.

실제 교실 학생의 장시간 관찰은 이번 자동화 점검 범위 밖이므로, 다음 수업에서 3~4학년 2명 이상에게 위 질문을 자기 말로 답하게 해 추가 확인합니다.
