## 자동 검증 결과

- [x] 5개 가상 사건과 안내 활동은 `validateCaseContent`의 ID·단계·안전 전달문 검사를 통과했습니다.
- [x] 원문, 인접 전달 단계, 안전 전달문 사이의 의미 ID를 도메인 테스트가 검사합니다.
- [x] 빠짐은 이전 문장의 사라진 조각, 다른 변화는 다음 문장 조각을 정확히 선택해야 합니다.
- [x] 필수 뜻·도움 뜻, 근거 없는 추가, 복수 변화와 복수 안전 전달문을 자동 테스트로 확인합니다.

## 교사의 사람 검토가 필요한 항목

- [ ] 가상 사건이 실제 학생·교직원·가족 정보를 연상시키지 않는지 수업 전 확인합니다.
- [ ] 두 학년군의 어휘와 비교 부담이 실제 학급 수준에 맞는지 확인합니다.
- [ ] 실제 긴급·안전 안내와 혼동되지 않는 안내 문구인지 확인합니다.

자동 검증은 데이터 일관성을 확인할 뿐, 한국어 표현과 초등 수업 적합성에 대한 교사 승인이나 수업 검토를 대신하지 않습니다. 아직 교사 승인 기록은 없습니다.
