# 진행 기록

## 2026-07-18 · v0.3.0

- 3~4학년과 5~6학년 활동의 학생용 문구를 쉬운 말로 다듬고, 답을 고친 뒤 다시 확인할 수 있는 선택 복구를 넣었습니다.
- 연습·비교·전체 보기·전달문 화면에 뒤로가기를 연결해, 이미 찾은 변화와 완료 기록은 남기고 아직 확인하지 않은 답만 다시 고를 수 있게 했습니다.
- 결과 화면은 실제로 찾은 변화와 그 이유만 보여 주어 빈 결과 카드를 반복하지 않게 했습니다.
- 화면이 바뀔 때마다 맨 위에서 시작하게 해, 결과 제목이 아래 스크롤 위치에 가려지지 않게 했습니다.
- 업데이트 내역에 `2026-07-18 · v0.3.0`을 추가했습니다.

## 2026-07-17 · v0.2.0

- 사건 선택부터 결과까지 현재 위치를 알 수 있는 5단계 진행 표시를 추가했습니다.
- 전달 매체를 안내문·말·메모·방송으로 한국어로 표시하고, 비교와 안내 활동에 1·2·3 선택 순서를 넣었습니다.
- 모바일 헤더를 관리 버튼과 학습 상태로 다시 묶고, 관리 버튼·선택 레이블·입력 요소의 터치 크기를 키웠습니다.
- 사건 개요의 매체 표시도 한국어로 통일하고, 안내 활동의 실제 표현 카드 영역을 1번 선택 그룹으로 명확히 표시했습니다.

## 2026-07-17 · v0.1.0

- 두 학년군 항로와 5개 가상 통신 사건을 연결했습니다.
- 인접 단계 의미 변화 판정, 전체 의미 장부, 안전 전달문 활동을 구현했습니다.
- 개인정보 비수집·비저장 원칙과 교사용 안전 안내를 화면에 포함했습니다.
