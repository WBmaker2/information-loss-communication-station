# 진행 기록

## 2026-07-17 · v0.2.0

- 사건 선택부터 결과까지 현재 위치를 알 수 있는 5단계 진행 표시를 추가했습니다.
- 전달 매체를 안내문·말·메모·방송으로 한국어로 표시하고, 비교와 안내 활동에 1·2·3 선택 순서를 넣었습니다.
- 모바일 헤더를 관리 버튼과 학습 상태로 다시 묶고, 관리 버튼·선택 레이블·입력 요소의 터치 크기를 키웠습니다.
- 사건 개요의 매체 표시도 한국어로 통일하고, 안내 활동의 실제 표현 카드 영역을 1번 선택 그룹으로 명확히 표시했습니다.
