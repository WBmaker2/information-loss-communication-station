# 접근성 점검표

- [x] 키보드 Tab, Enter, Space로 모든 선택과 이동이 가능하다.
- [x] 표현 조각은 `button`과 `aria-pressed`를 사용한다.
- [x] 변화 유형은 라디오 그룹, 뜻 근거는 체크박스와 `fieldset`/`legend`를 사용한다.
- [x] 판정 피드백은 `aria-live="polite"`로 알린다.
- [x] 안내 창은 제목, 닫기 버튼, 초기 닫기 버튼 초점을 제공한다.
- [x] 360px에서 한 열로 바뀌고 가로 스크롤이 없다.
- [x] `prefers-reduced-motion`에서 전환과 애니메이션을 제거한다.
